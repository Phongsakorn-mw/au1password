# OtterVault - Google Chrome Extension Specification (Phase 2)

## 1. Overview & Interoperability Objective

OtterVault's Chrome Extension allows users to access and autofill their credentials, view notes, and preview secure images directly in the browser. 

The extension uses the exact same encrypted vault format (`otter-vault-v1`) stored in Google Drive (`appDataFolder/otter-vault.enc`), maintaining zero-knowledge encryption:
- Google Drive only sees encrypted ciphertext envelopes.
- Decryption occurs entirely inside the extension's isolated sandbox using the browser's native **WebCrypto API** (`window.crypto.subtle`).
- No plaintext credentials or master passwords are ever transmitted over the network or saved in unencrypted storage.

## 2. Vault Envelope Format Compatibility

The envelope generated by Rust (`otter-crypto`) is 1:1 compatible with standard WebCrypto:

```json
{
  "version": 1,
  "format": "otter-vault-v1",
  "kdf": {
    "algorithm": "PBKDF2-HMAC-SHA256",
    "salt_base64": "<32 bytes base64>",
    "iterations": 250000
  },
  "cipher": {
    "algorithm": "AES-256-GCM",
    "iv_base64": "<12 bytes base64>",
    "tag_base64": "<16 bytes base64>"
  },
  "ciphertext_base64": "<encrypted payload base64>",
  "meta": {
    "last_modified": 1732272000,
    "item_count": 6
  }
}
```

## 4. WebCrypto Implementation Reference

WebCrypto decrypts `otter-vault-v1` without external npm dependencies:

```javascript
// Base64 helper
function base64ToBytes(b64) {
  return Uint8Array.from(atob(b64), c => c.charCodeAt(0));
}

// 1. Derive AES-GCM Key from Master Password via PBKDF2
async function deriveMasterKey(password, saltBytes, iterations) {
  const enc = new TextEncoder();
  const keyMaterial = await crypto.subtle.importKey(
    "raw",
    enc.encode(password),
    { name: "PBKDF2" },
    false,
    ["deriveKey"]
  );

  return crypto.subtle.deriveKey(
    {
      name: "PBKDF2",
      salt: saltBytes,
      iterations: iterations,
      hash: "SHA-256"
    },
    keyMaterial,
    { name: "AES-GCM", length: 256 },
    false,
    ["encrypt", "decrypt"]
  );
}

// 2. Decrypt Vault Envelope
async function decryptVaultEnvelope(envelope, password) {
  if (envelope.format !== "otter-vault-v1") {
    throw new Error("Unsupported vault format: " + envelope.format);
  }

  const salt = base64ToBytes(envelope.kdf.salt_base64);
  const iv = base64ToBytes(envelope.cipher.iv_base64);
  const tag = base64ToBytes(envelope.cipher.tag_base64);
  const ciphertext = base64ToBytes(envelope.ciphertext_base64);

  // WebCrypto AES-GCM expects [ciphertext + tag] concatenated
  const combined = new Uint8Array(ciphertext.length + tag.length);
  combined.set(ciphertext, 0);
  combined.set(tag, ciphertext.length);

  const aesKey = await deriveMasterKey(password, salt, envelope.kdf.iterations);

  const decryptedBytes = await crypto.subtle.decrypt(
    {
      name: "AES-GCM",
      iv: iv,
      additionalData: new TextEncoder().encode("otter-vault-v1")
    },
    aesKey,
    combined
  );

  const decryptedJson = new TextDecoder().decode(decryptedBytes);
  return JSON.parse(decryptedJson);
}
```

## 5. Google Drive Sync via `chrome.identity`

The Chrome Extension uses `chrome.identity.getAuthToken` for native Google login:
```javascript
chrome.identity.getAuthToken({ interactive: true }, function(token) {
  if (chrome.runtime.lastError || !token) {
    console.error("Auth failed:", chrome.runtime.lastError);
    return;
  }
  
  // Download otter-vault.enc from appDataFolder
  fetch("https://www.googleapis.com/drive/v3/files?spaces=appDataFolder&q=name='otter-vault.enc'", {
    headers: { Authorization: "Bearer " + token }
  })
  .then(res => res.json())
  .then(data => {
    if (data.files && data.files.length > 0) {
      const fileId = data.files[0].id;
      return fetch(`https://www.googleapis.com/drive/v3/files/${fileId}?alt=media`, {
        headers: { Authorization: "Bearer " + token }
      }).then(r => r.json());
    }
  })
  .then(envelope => {
    console.log("Vault envelope received from Google Drive:", envelope);
  });
});
```
